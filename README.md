# NuRelax (Football Progress Bot) ⚽️

Telegram-бот для записи и отслеживания футбольных тренировок. 
Помогает фиксировать количество повторений и следить за прогрессом.

## 🛠 Стек технологий
* **Язык:** Python 3
* **Библиотека:** python-telegram-bot
* **Среда разработки:** GitHub Codespaces (облако)

## 🚀 Как запустить проект
1. Склонируйте репозиторий.
2. Установите зависимости:
   `pip install python-telegram-bot`
3. Создайте секрет `TELEGRAM_BOT_TOKEN` в настройках вашего Codespaces (или задайте переменную окружения) и поместите туда токен от BotFather.
4. Запустите бота:
   `python main.py`

## 📱 Текущие команды
* `/start` — приветствие и начало работы
* `/help` — список доступных команд
* `/add <число>` — добавить тренировку (например, `/add 30`)
* `/stats` — посмотреть статистику (количество тренировок и общее число повторений)
